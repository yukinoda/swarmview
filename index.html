What do these numbers mean?
Agents and repository counts
The header counts detected agents, excluding subagents. Repository and worktree counts show working and waiting agents by name and color.
Status and Needs you
Working means recent CPU activity, not task progress. Waiting means previously active, now quiet; network or I/O waits can look the same. After 15 seconds waiting, an agent appears in Needs you. New means just started; idle means no recent observed activity; exiting means just disappeared.
RAM ~1.6 GB
Approximate resident memory of an agent and its child processes. Shared pages may be counted more than once. Amber starts at 500 MB; red at 1.5 GB. These are size hints, not errors or system memory pressure.
up 1h
Agent process age, not time spent on the current task. Subagent rows show the model here instead.
CPU 36%
Recent CPU use including child processes. 100% is one CPU core; multi-core work can exceed 100%. This is not percent complete. Shown while working.
OpenCode · dev:%42
Agent name and tmux session/pane target, not a metric. Click an enabled task row to select its terminal pane. Outside tmux, agents are monitoring-only.
System swap / RAM free
Machine-wide indicators, available on macOS. Swap is disk space used for virtual memory; RAM free is the macOS-reported available-memory percentage.
Last updated
Age of the last snapshot. If offline appears, the visible data is retained and keeps aging while Swarmview retries.
Reclaim memory
Up to three idle agents using at least 300 MB each. This is a suggestion; Swarmview does not close them or free their memory.
