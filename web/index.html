Details: CPU, process age & metric definitions
Agents and repository counts
The header counts detected agents, excluding subagents. Repository and worktree counts show working and quiet agents, plus detected workers.
State and Recently quiet
Working means recent CPU activity (or subagent log writes), not task progress or communication. Quiet means previously active, now quiet; network, tools, workers, and human input cannot be distinguished. Idle means no recent observed activity; new means just started; exiting means just disappeared. Quiet never means finished or a request for help. Unknown means activity telemetry is unavailable.
RAM ~1.6 GB
Approximate resident memory of an agent and its child processes, excluding separately listed agents. Shared pages may be counted more than once, so values are not exact additive physical RAM or reclaimable memory. Large values alone are not warnings. A dash means unavailable, including per-worker RAM.
Per-agent details
Click State or RAM to show CPU, process age, model and terminal context where available, or to fold a worker branch. Details work for monitoring-only agents too. Click an enabled task to open its terminal; this is a separate action.
Process age / CPU 36%
Process age is not time spent on the current task. CPU includes child processes; 100% is one CPU core and multi-core work can exceed 100%. This is not percent complete. Worker CPU and process age are unavailable.

Agent name and tmux session/pane target, not a metric. Outside tmux, agents are monitoring-only.
System pressure / swap / RAM free
Waiting for system snapshot.
Machine-wide indicators, available on macOS. Only actual OS pressure (normal, warning or critical) sets warning severity. Normal pressure is in the header tooltip and these details when swap/free context is shown. Swap is disk space used for virtual memory, not current pressure; RAM free is the macOS-reported available-memory percentage. Missing pressure telemetry is explicitly unavailable.
Last updated
Age of the last snapshot. If offline appears, the visible data is retained and keeps aging while Swarmview retries.
Recently quiet notifications
At most three observations are shown, from 15 seconds to 5 minutes quiet, after activity was observed in this page session. Optional notifications and tab counts use that same observation (the tab counts all matches), not a human request. No agents are closed automatically.
Hierarchy and communication
Lines show detected parentage only. Communication events are unavailable, so there are no send/reply pulses. No conversation contents or extra event polling are collected.
